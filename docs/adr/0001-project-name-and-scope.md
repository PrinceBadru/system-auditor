# 0001 — Project name and scope

- Status: Accepted
- Date: 2026-10-10

## Context

The project is intended to analyze systems and infrastructure and provide
actionable, environment-specific insights. The original name, `system-cleaner`,
could suggest that the software deletes files or performs automated cleanup,
which is not the project's stated goal.

## Decision

Name the project **System Auditor** (`system-auditor`) and describe its purpose
as examining systems, identifying potential issues and improvement
opportunities, and communicating findings. Do not imply that a particular
environment, audit check, report format, or implementation already exists until
those capabilities are defined and built.

## Consequences

- The project name better communicates analysis and assessment rather than
  automatic cleanup.
- Documentation should distinguish the intended direction from implemented
  functionality.
- Supported environments and auditing behavior remain open decisions for
  future records.
